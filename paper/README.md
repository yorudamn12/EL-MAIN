**Build the PDF.** The simplest way is Overleaf: upload `main.tex` and `references.bib`, then compile with pdfLaTeX
and BibTeX. Without LaTeX, you can build the printed copy instead:

```
python paper/build_html.py paper paper/paper_preview.html paper/paper.css
```

Then print `paper_preview.html` to PDF from a browser.

**Rules for the text.** Every number must come from `docs/RESULTS.md` or `paper_runs/`, and every reference must be
checked against its arXiv, ACL, DOI or publisher page (`references.bib` records what was checked). Write all prose
fresh, so it passes plagiarism checks. Still open: authors' affiliations and corresponding e-mail (the red TODO
in `main.tex`).
